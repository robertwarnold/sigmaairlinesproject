# Research dashboard design

Operate mode for experiment tabs; Read mode for the academic poster.
Poster opens first, per the proposed classroom presentation flow and user continuation.
Use a warm paper surface (#f7f5ef), dark ink (#172b36), deep teal (#145e63) and amber
(#966021) for pending evidence. Red (#a33432) is reserved for failed checks.
Use readable locally available sans-serif for controls and serif for the research
question, tabular numerals for observations. No remote fonts or decorative imagery.
The poster has an editorial title band, two large side-by-side figures, and a clear
five-part academic narrative. Tabs use simple tables and a fixed evidence-status strip.
Charts share palette and labels across app/PDF. Every pending panel names the missing
evidence. Mobile layouts stack; projected poster keeps a 16:9 minimum canvas.


## V4.1 refinement (explicit user brief)
Mission control opens first; six task-based views reuse the existing Shiny components.
Dark tokens replace paper tones: background #0c1118, panels #111820, raised #17212c,
text #e9f0f6, muted #aebdcb, cool accent #6ac9df, warning #d4b774, failure #df9492.
KPI row uses restrained text hierarchy and meaningful denominators, not crowded cards.
Tables, filters, plots and poster share tokens; projection mode can hide navigation.
No gradients, neon decoration or network-hosted fonts. Keyboard focus remains visible.
